# list.append()
The append() method in Python is used to add an element to the end of a list.
# list.clear()
The clear() method in Python is used to remove all elements from a list, leaving it empty. It modifies the original list in place rather than creating a new one.
# list.copy()
The copy() method in Python is used to create a duplicate of a list without modifying the original. It returns a new list with the same elements.
# list.count()
This method is used with lists to return the number of occurrences of a specified value.
# list.exted()
extend() method in Python is used to add the elements of an iterable (like a list, tuple, or set) to the end of an existing list. It modifies the original list rather than creating a new one.
# list.index()
The index() method in Python is used to find the first occurrence of a specified value in a list. It returns the index position of that value. If the value is not found, it raises a ValueError.
# list.insert()
The insert() method in Python allows you to add an element at a specified position within a list. It shifts existing elements to accommodate the new one instead of replacing them.
# list.pop()
The pop() method in Python is used to remove and return an element from a list at a specified index. If no index is provided, it removes and returns the last element by default.
# list.remove()
The remove() method in Python is used to delete the first occurrence of a specified value from a list. If the value is not found, it raises a ValueError.
# list.reverse()
are you referring to the reverse() method in Python? This method reverses the order of elements in a list in place, meaning it modifies the original list rather than creating a new one.
# list.sort()
The sort() method in Python is used to arrange the elements of a list in ascending order by default. You can also sort in descending order by specifying reverse=True.
