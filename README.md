# dictionary.clear()
method is used to remove all elements from a dictionary, leaving it empty.
# dictionary.copy()
The copy() method in Python dictionaries creates a shallow copy of the dictionary. This means that it duplicates the dictionary but does not copy nested objects—those remain references to the original.
# dictionary.fromkeys.py()
The fromkeys() method in Python dictionaries is used to create a new dictionary with specified keys and a single shared value for all keys.
# dictionary.get()
The get() method in Python dictionaries is used to retrieve the value of a specified key. If the key is not found, it returns None by default or a specified fallback value.
# dictionary.items()
The items() method in Python dictionaries returns a view object containing key-value pairs as tuples. This view object reflects any changes made to the dictionary.
# dictionary.keys()
The keys() method in Python dictionaries returns a view object containing all the keys in the dictionary. This view is dynamic, meaning it reflects any changes made to the dictionary.
# dictionary.pop()
The pop() method in Python dictionaries removes a specified key and returns its value. If the key is not found, you can provide a default value to return instead of raising an error.
# dictionary.popitems()
The popitem() method in Python dictionaries removes and returns the last inserted key-value pair as a tuple. This method follows a Last In, First Out (LIFO) order, meaning the most recently added item is removed first.
# dictionary.setdefault()
The setdefault() method in Python dictionaries returns the value of a specified key. If the key does not exist, it inserts the key with a given default value.
# dictionary.update()
The update() method in Python dictionaries is used to add key-value pairs from another dictionary or an iterable of key-value pairs. If a key already exists, its value is updated.
# dictionary.values()
The values() method in Python dictionaries returns a view object containing all the values in the dictionary. This view is dynamic, meaning it updates automatically if the dictionary is modified.
