# list.append()
The append() method in Python is used to add an element to the end of a list.
# list.clear()
The clear() method in Python is used to remove all elements from a list, leaving it empty. It modifies the original list in place rather than creating a new one.
# list.copy()
The copy() method in Python is used to create a duplicate of a list without modifying the original. It returns a new list with the same elements.
